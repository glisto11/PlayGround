## 24 ZONE

Four numbers. One target. Every move counts.

A fast neon number puzzle: combine four tiles with **+ − × ÷** to reach exactly **24**, using every tile once. Exact fractions are allowed. Clear three puzzles to open the next zone, race the clock, and build a streak. Hints cost points; resets cost time.

- Fully static — `index.html`, `styles.css`, `game.js`.
- Puzzle generator verifies every deal is solvable with exact rational arithmetic.
- Touch-first layout, responsive down to small phones, safe-area aware.
- Keyboard support: `1–4` tiles, `+ - * /` operators, `U` undo, `R` reset, `H` hint, `M` mute.
- Best score and sound preference are saved locally.

Run locally with `./start.sh` (static server on `$PORT`, default `3000`) or open `index.html` through any static file server.
